# 全相異最長共同子序列
## 題目意思
給定兩個由小寫英文字母與數字組成的字串，請找出它們所有的「最長共同子序列 (Longest Common Subsequence, LCS)」。為了方便核對，請算出共有多少種不同的最長共同子序列，並將這些相異的序列按照字典順序（從小到大）逐一列出。

## 輸入格式
第一行包含一個整數 T，代表測試資料的筆數。
接下來有 T 組測試資料，每組測資包含兩行，分別為字串 A 與字串 B。

## 輸出格式
對於每組測試資料，第一行請輸出 Case #X: Y，其中 X 為測資編號（從 1 開始），Y 為該組測資中「不同最長共同子序列」的數量。
接著，將所有不同的最長共同子序列按照字典順序輸出，每一個序列佔一行。

## 範圍限制
字串長度 L 滿足 1 <= L <= 32。

字串僅由小寫英文字母與數字構成。

每一組測資不同的最長共同子序列總數不超過 100000 個。

## 記憶體限制：512MB

## 時間限制：1s

# 全相異最長共同子序列

## 題目想法

這題除了要求找出兩個字串的最長共同子序列（LCS）長度，更進一步要求還原出所有「相異」的最長子序列。
相較於單純求長度，這題的重點在於如何根據動態規劃的狀態反推路徑，並且妥善處理重複的字串組合。

## 解題過程

建構完整 DP 陣列：先依照常規的 LCS 狀態轉移方程式建立二維陣列求出最大長度。
因為後續需要進行還原，無法利用倒序處理的方式將 DP 陣列壓縮成一維，必須保留完整的二維狀態。
狀態反推與回溯：將原本求動態規劃的過程倒過來，從陣列右下角（最後一個字元）開始往回推。
利用 Stack 進行迭代式的回溯，每當遇到分支（兩邊 DP 值相同）就分別走訪。
去重與排序：利用 set 儲存反推出來的路徑字串，一次解決過濾重複子序列與維持字典順序輸出的兩個需求。

## 解題方法思考

最近剛好在實作萊文斯坦距離（Levenshtein distance），發現 LCS 與它的核心概念有異曲同工之妙。

兩者都是針對字串 A 的前 $i$ 個字元與字串 B 的前 $j$ 個字元進行狀態轉移。

不同之處在於，萊文斯坦距離需要綜合考量刪除、插入與替換的成本，而 LCS 的狀態轉移則單純許多——字元相同就加一，不相同就直接從 dp[i-1][j] 或 dp[i][j-1] 取最大值。

## 複雜度分析

### 時間複雜度：

建構 DP 陣列為 O(N * M)（N、M 為字串長度）。
回溯尋找所有路徑在最差情況下可能達到指數級別，加上 set 維護字串的時間，整體時間取決於測資的路徑分支數量。

### 空間複雜度：

O(N * M)。

因為需要保留完整狀態進行路徑回溯，無法進行空間壓縮。
加上 stack 與 set 的額外儲存空間。
## 學習心得

隔了一陣子重新接觸 LCS，起初記憶有些模糊，但藉由近期對萊文斯坦距離的深入研究，反而能從更高的視角將兩個字串 DP 演算法互相對照。
理解到只要完整保留 DP 過程的狀態，就能從終點反向推回起點，找出所有可能的最佳解路徑。
這次實作不僅重新熟悉了 LCS，也更深刻體會到動態規劃中「狀態設計」與「路徑還原」的關聯性。
