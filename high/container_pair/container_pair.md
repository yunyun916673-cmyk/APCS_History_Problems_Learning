# 港口貨櫃裝卸的逆序配對
## 題目想法
給定一個長度為 n 的序列，計算所有滿足 i < j 且 a[i] > a[j] 的數對數量。最直覺的想法是枚舉每一組 (i, j) 進行比較，但當 n 達 10^5 時，平方級別的枚舉會超出時間限制，因此需要用更有效率的方式統計「較小元素出現在較大元素右側」的次數。

## 解題過程
先寫出雙層迴圈暴力枚舉版本，確認題意與小測資邏輯無誤，並注意到答案上限可達 n*(n-1)/2（約 5 * 10^9），需使用 long long 型別儲存。

改用合併排序（Merge Sort）的分治架構，在將左右兩個已排序子陣列合併時，順便統計跨區間或左半部造成的逆序數量。

當右半部元素小於左半部元素時，由於左右兩側皆已遞增排序，左半部從目前指標到中點之間的所有元素都會大於該右半部元素，可直接一次累加數量。

## 解題方法思考
暴力枚舉：實作簡單、不易出錯，適合小範圍測資或拿來當作對拍基準，但在 n=10^5 的量級下時間複雜度過高。

分治合併排序：在排序過程中自然完成大小關係比對，不需要額外建構複雜資料結構就能在 O(n log n) 內算完逆序數；合併時要注意等號條件，避免將相等數值誤判為逆序對。

其他可行方向：若搭配離散化與樹狀陣列（BIT）或平衡樹，也能以相同時間複雜度從右往左或由小到大動態統計。

## 複雜度分析
### 暴力枚舉：
#### 時間複雜度 O(n^2)
#### 空間複雜度 O(n)

### 分治合併排序：
#### 時間複雜度 O(n log n)
#### 空間複雜度 O(n)

## 學習心得
這題讓我更清楚體會到「在演算法過程中順便維護所需資訊」的威力，把原本需要 O(n^2) 逐對檢查的逆序數量，透過合併排序的分治特性壓低到 O(n log n)。
