# 燈塔光譜
## 題目意思
在古老的群島航道上，工程師用一串由字元 0、1、2 組成的訊號序列 S 來描述一座階層式的號誌燈塔網路結構：

0 表示目前的燈塔節點沒有下層分支。

1 加上子序列 S1 表示目前的燈塔節點有一個下層分支，而 S1 描述該分支的完整結構。

2 加上兩個子序列 S1 與 S2 表示目前的燈塔節點有兩個下層分支，分別由 S1 與 S2 描述。

整座燈塔網路的每個節點都可以安裝琥珀色、翡翠色或靛藍色其中一種濾光鏡。為了避免航行員誤判訊號，必須滿足以下限制：

任一節點與其直接相連的子節點，濾光鏡顏色不可相同。

若某節點有兩個子節點，這兩個子節點彼此之間的濾光鏡顏色也不可相同。

請根據給定的訊號序列 S，計算整座網路中安裝翡翠色濾光鏡的節點數量「最多」與「最少」各可以是幾個。

## 輸入格式
輸入僅有一行，包含一個合法的訊號序列字串 S。

## 輸出格式
輸出一行包含兩個整數，以空白隔開，依序代表翡翠色濾光鏡節點數量的最大值與最小值。

## 範圍限制
訊號序列 S 長度合理，節點總數與邊數皆在一般樹狀動態規劃可處理的範圍內（完整結構由序列 S 唯一決定）。

答案保證落在一般 64 位元帶號整數可表示的範圍內。

# 燈塔光譜
## 題目想法
題目給定由 0、1、2 組成的先序式二叉树序列 S，先將其還原為樹狀結構，再為每個節點指定三種顏色之一（可對應紅、綠、藍三種狀態），並滿足「父子不同色」以及「同節點的兩個子節點彼此不同色」。
目標是求出整棵樹中指定目標顏色節點數量的最大值與最小值。解題過程序列建樹：利用遞迴搭配全域指標 pos 依序讀取字元 S[pos]，目前節點的子節點數為 cur = S[pos] - '0'，隨後遞迴建立 cur 棵子樹並建立雙向鄰接表。
樹狀動態規劃：以根節點為起點進行後序走訪，計算每個節點在三種顏色狀態下的最佳值（求最大值時取 max，求最小值時取 min）。
分岔狀態合併：當節點有兩個子節點時，枚舉兩個子節點在合法不衝突前提下的顏色搭配組合，將子樹結果合併至當前節點，最後於根節點彙整出最大值與最小值。
## 解題方法思考
這題的核心在於把「字串描述的樹形結構」轉換成「可做子樹 DP 的樹狀圖」，並在狀態轉移時嚴格守住相鄰與兄弟節點的顏色互斥條件。分開執行最大值與最小值兩次 DP 雖然邏輯直覺，但其實可以把極值運算抽離出來共用同一套走訪框架；
此外，將偏縮寫的變數名稱改為語意化名稱，也能讓這份解題紀錄在 GitHub 上更容易被自己日後回顧與他人閱讀。
## 複雜度分析
### 時間複雜度：
令樹的邊數為 N、節點數為 N + 1。建樹需走訪序列一次，最大值與最小值各做一次樹狀 DP，每個節點與邊皆只會被常數次處理，整體時間複雜度為 O(N)。
### 空間複雜度：
鄰接表、DP 陣列與遞迴呼叫堆疊深度在最壞情況下皆與節點數成線性關係，整體空間複雜度為 O(N)。
## 學習心得
透過這題再次體會到樹狀 DP 的關鍵不在於寫出多複雜的程式，而在於狀態定義是否完整以及多子節點合併時的邊界是否考慮周全。只要先把樹的拓撲建穩、把顏色衝突條件拆清楚，最大與最小的轉移就能自然對稱地完成。
