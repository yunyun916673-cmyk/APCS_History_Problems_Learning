# 基地台

## 題目敘述

給定 N 個服務點位於一條直線上，每個服務點都有自己的座標。公司需要架設 K 個基地台，且所有基地台的服務半徑相同。

一個基地台可以服務距離基地台位置不超過半徑 R 的所有服務點，也就是服務直徑為 D = 2R 的範圍。

請找出最小的基地台直徑 D，使得架設 K 個基地台後，所有服務點都能被至少一個基地台覆蓋。

## 輸入格式

第一行包含兩個整數 N、K，表示服務點數量與基地台數量。

第二行包含 N 個整數 P[i]，表示每個服務點的座標。


## 輸出格式

輸出最小的基地台直徑 D。

# 基地台

## 題目想法

一開始看到這個題目的時候，我第一個想到的是基地台的位置問題。因為基地台可以放在任意位置，所以原本想過是不是需要利用除法計算基地台的中心位置。

但是這樣會遇到小數精度的問題，而且其實題目要求的是最小直徑，並不是基地台的位置。因此我後來發現，其實不需要真的求出基地台放在哪裡，只需要知道一個基地台能夠覆蓋多少範圍即可。

因為題目中的座標範圍可能比較大，所以我使用 long long 來避免計算時可能發生的溢位。

思考後，我決定使用二分搜尋答案。假設目前猜測一個直徑，利用 check 函式判斷這個直徑是否能使用 K 個基地台覆蓋所有接收器。

## 解題過程

首先建立題目要求的 N 和 K，並建立 vector `points` 儲存所有接收器的位置。

接著建立 check 函式，參數為目前假設的基地台直徑 Rad，用來判斷這個直徑是否可行。

在 check 裡面，我使用 used 記錄目前使用了多少個基地台，並使用 i 作為目前掃描接收器的位置。

每次進入迴圈時，代表需要新增一個基地台，因此先增加 used，如果基地台數量超過 K，就代表目前的直徑無法覆蓋所有接收器，回傳 false。

接著利用 cnt 紀錄目前基地台可以覆蓋到的最右位置：

cnt = points[i] + Rad

因為基地台不需要真的放在接收器上，只要從目前最左邊尚未覆蓋的點開始計算，就可以得到這個基地台最多能服務的位置。

之後利用 while 迴圈持續更新 i，跳過所有已經被基地台覆蓋的接收器。

完成 check 後，回到 main 函式。

先輸入所有資料，將接收器位置排序，接著利用二分搜尋尋找最小可行直徑。

如果目前直徑可以覆蓋所有接收器，就嘗試更小的答案；如果不行，就增加直徑範圍。

最後輸出找到的最小直徑。

## 解題方法思考

這題最重要的地方是不要被基地台的位置限制住。

一開始我認為需要計算基地台中心位置，但後來發現其實只需要知道基地台能覆蓋的範圍即可。

因此將問題轉換成：

假設基地台直徑為 D，最多使用 K 個基地台能不能覆蓋所有接收器？

這樣就可以利用二分搜尋答案。

而在 check 函式中，使用貪心的方法，每次都讓基地台從目前最左邊未覆蓋的位置開始覆蓋，可以保證單一基地台能服務最多接收器。

## 複雜度分析

### 時間複雜度：

O(N log N + N log M)

排序所有接收器位置需要 O(N log N)，二分搜尋答案時需要 log M 次判斷，每次 check 都會掃描一次所有接收器，因此為 O(N)。

### 空間複雜度：

O(N)

需要使用 vector 儲存所有接收器的位置。

## 學習心得

這題讓我學到，遇到幾何或位置相關的問題時，不一定需要真的求出物體的位置，有時候只需要觀察它造成的範圍變化即可。

一開始我想利用基地台位置進行計算，但後來發現直接利用直徑判斷覆蓋範圍會更加簡單，也避免了小數精度問題。

另外，這題也讓我更熟悉二分搜尋答案的使用方式。重點是設計一個 check 函式判斷某個答案是否可行，再利用二分搜尋縮小範圍。
