# 牆上海報

## 題目意思

有一排由 `n` 塊木板組成的柵欄，每塊木板都有自己的高度。現在有 `k` 張海報，每張海報都有指定的寬度，而且高度都是 `1`。

所有海報必須按照給定順序貼在柵欄上，且每張海報都要放在同一個高度 `x`。對於一張寬度為 `w[i]` 的海報，必須找到 `w[i]` 塊連續的木板，而且這些木板的高度都至少為 `x`。海報之間不能重疊，但可以緊貼在一起。

請找出所有海報都能依序貼上的情況下，能達到的最大高度。 ([ZeroJudge](https://zerojudge.tw/ShowProblem?problemid=h084\&utm_source=chatgpt.com "h084. 4. 牆上海報 - 高中生程式解題系統"))

## 輸入格式

第一行輸入兩個正整數 `n`、`k`。

第二行輸入 `n` 個正整數，依序表示每塊木板的高度 `h[i]`。

第三行輸入 `k` 個正整數，依序表示每張海報的寬度 `w[i]`。

## 輸出格式

輸出所有海報按照順序貼上後，能達到的最大高度。 

- `1 <= n <= 200000`
- `1 <= k <= 5000`
- `1 <= h[i] <= 10^9`
- `sum(w[i]) <= n`
- 記憶體限制：`512 MB`

# 牆上海報

## 題目想法

一開始看到這個題目的時候，我其實卡了很久，因為一開始沒有找到很明確的解法。後來我重新仔細看了一次題目，才發現自己漏看了兩個很關鍵的資訊，第一個是每一張海報都必須在同一個高度，第二個是海報必須按照給定的順序張貼。

補上這兩個條件之後，我才發現這個題目其實簡單很多。

因為題目問的是能夠張貼海報的最大高度，所以我可以考慮對高度進行二分搜尋。假設現在檢查高度 x，如果高度 x 都沒有辦法把所有海報放完，那麼高度比 x 更高的情況也一定不可能完成。

所以這個答案具有單調性，可以使用二分搜尋。

接下來只需要想辦法檢查一個高度是否可行就好。

因為所有海報都必須按照順序張貼，所以我不需要考慮海報之間不同的排列方式，只需要從左到右一直走，而且不需要回頭。只要目前累積到的連續木板寬度可以放下第一張海報，就把第一張放進去，再繼續處理第二張、第三張，最後確認是否能夠按照順序把所有海報都放完。

## 解題過程

我在 check 中先固定一個要檢查的高度 ove，然後從第一塊木板開始往後掃描。

如果目前木板的高度至少為 ove，代表這塊木板可以拿來貼海報，因此我就把連續可使用的寬度 cnt 加一。

如果遇到高度小於 ove 的木板，代表目前的連續區間被切斷了。這時候我就利用剛才累積的 cnt，開始按照順序處理海報。

如果目前的連續寬度 cnt 大於等於正在處理的海報寬度 W[tag]，就代表這張海報可以放進去，所以我把這張海報放掉，並且把 cnt 減掉這張海報所需要的寬度，再繼續看下一張海報。

如果 cnt 已經不足以放下目前的海報，就代表這個連續區間沒有辦法再放下一張海報，因此把 cnt 歸零，重新尋找下一個可以使用的連續區間。

掃描完所有木板之後，如果所有海報都已經按照順序放完，就代表目前的高度可以達成。

最後在 main 中對高度進行二分搜尋。如果 check(mid) 可以成功，就代表 mid 這個高度可以做到，因此繼續往更高的高度搜尋；如果不能做到，就往更低的高度搜尋。

這樣就可以找到所有海報都能按照順序貼上的最大高度。

## 解題方法思考

這一題讓我比較有感覺的是，題目的限制條件其實會直接影響解法。

一開始如果沒有注意到每張海報都在同一個高度，而且還必須按照順序張貼，就會覺得要考慮的情況很多，也很難找到方向。

但仔細看完題目之後，我發現這兩個條件把問題限制得非常明確。

固定一個高度之後，我只需要從左到右掃描，不需要回頭，也不需要考慮海報的排列方式。只要維護目前連續可以使用的木板寬度，再按照順序把海報放進去即可。

而因為高度越高，能使用的木板只會越少，所以如果高度 x 無法完成，那麼比 x 更高的高度也不可能完成。利用這個單調性，就可以使用二分搜尋答案。

因此最後的做法就是二分搜尋高度，再用 check 線性判斷這個高度是否可行。

## 複雜度分析

### 時間複雜度：

O((n+k) log(max(H)))

每次 check 都會從頭到尾掃描木板，並且海報也只會按照順序處理一次，所以一次 check 的複雜度為 O(n+k)。外層再對高度進行二分搜尋，因此總時間複雜度為 O((n+k) log(max(H)))。

### 空間複雜度：

O(n+k)

需要使用陣列儲存所有木板高度以及海報寬度。

這題也讓我再次熟悉了二分搜尋答案的用法。以前看到二分搜尋，我比較容易想到是在一個已經排序好的陣列中找東西，但這題讓我發現，只要答案具有單調性，就算答案本身不是陣列中的元素，也可以透過 check 函數判斷一個答案是否可行，再利用二分搜尋找出最大的可行值。
