# 存儲
## 題目意思
老港灣的貨櫃碼頭有一座總容量為 M 的大型冷鏈倉庫，目前已經堆放了 N 批漁獲貨物，第 i 批貨物佔用的空間為 v_i。碼頭排程員現在要安排一批新的冷凍集裝箱進駐，這批新箱子總共需要 S 的空間。

為了騰出足夠空間，排程員可以選擇把現有的部分（或全部，甚至不搬走任何一批）漁獲貨物暫時移往外圍備用倉儲。假設最終移走的所有貨物總體積為 X，那麼倉庫原本空出來的 M - summ（其中 summ 為 N 批貨物的總體積）加上移走的 X，只要大於或等於 S，就能順利容納新箱子。

請問在所有合法的「可被湊出的現有貨物體積總和 X」之中，滿足能讓新箱子順利進駐的最小 X 是多少？如果連原本的剩餘空間加上全部現有貨物都還不夠放新箱子，則輸出 0。

## 輸入格式
第一行包含三個整數 M、S、N，分別代表冷鏈倉庫總容量、新箱子所需空間，以及現有貨物批數。
第二行包含 N 個整數 v_1, v_2, ..., v_N，依序代表每批現有貨物的體積。

## 輸出格式
輸出一個整數，代表符合條件的最小可湊出移走貨物總和 X；若空間完全不足以容納新箱子，則輸出 0。

## 範圍限制
1 <= M, S <= 100000

1 <= N <= 200

1 <= v_i <= 100000

保證所有貨物體積總和不超過 M

# 存儲
## 題目想法
本題核心是從 N 件物品中挑選一個子集，使其重量或體積總和 X 恰好能被湊出，並找到大於等於最低需求門檻 K 的最小可行總和 X。先計算原本剩餘空間 M - summ，若原本空位就已經大於等於 S，代表不需要搬移任何物品，答案為 0；否則至少需要騰出 K = S - (M - summ) 的空間。

## 解題過程
讀入 M、S、N 與每件物品的體積 valume[i]，同時累加總體積 summ。

計算目前可用空檔 K = M - summ。若 K >= S，直接輸出 0 並結束程式。

將門檻更新為還需要額外騰出的最小體積 K = S - K。

初始化 bitset<100005> dp，令 dp[0] = 1 表示體積總和 0 可以被湊出。

依序走訪每件物品 valume[i]，利用左移位元運算 dp |= (dp << valume[i]) 更新所有可湊出的子集合法總和。

最後使用 dp._Find_next(K - 1LL) 尋找大於等於 K 的最小被設為 1 的索引位置並輸出。

## 解題方法思考
若使用傳統一維布林或整數 DP 陣列逐一轉移，雖然時間複雜度也是 O(N * MaxSum)，但在常數上較高。改用 std::bitset 搭配位元左移與位元或運算，能將多個狀態的轉移壓縮在機器字長內平行處理，大幅降低常數時間，非常適合這類狀態數在 10^5 左右、只需要記錄「能否湊出」的 0/1 背包子集和問題。此外，_Find_next(pos) 可以直接跳過不滿足下界的位元，省去手動迴圈掃描。

## 複雜度分析
### 時間複雜度：O(N * W / omega)
其中 N 為物品數量（最多 200），W 為位元集上限（100005），omega 為機器字長（通常為 64）。整體運算量極小，可在數毫秒內完成。

### 空間複雜度：O(W / 8)
bitset<100005> 約佔用 12.5 KB 記憶體，加上 vector<ll> 空間非常精簡。

這題讓我再次體會到把「能不能湊出某個總和」轉化成 bitset 位元位移的威力，寫法精簡而且常數極低。
