# 飛黃騰達

## 題目說明

飛黃是一種只能向右上方移動的生物，從座標 (0,0) 出發。平面上有 n 個果實，每個果實位於不同的座標 (x,y)。

飛黃只有在移動過程中經過某個果實的位置時才能吃到它。由於它只能往 **x 座標不減少、y 座標不減少** 的方向移動，因此需要找出一條符合移動限制的路徑，使經過的果實數量最多。

輸入會提供所有果實的位置，請輸出飛黃最多可以吃到的果實數量。

## 輸入說明

第一行輸入一個整數 n，代表果實的數量。

接下來有 n 行，每行輸入兩個整數 x, y，表示第 i 個果實所在的座標 (x, y)。

保證所有果實的位置皆不重複。

## 輸出說明

輸出一個整數，表示飛黃最多可以吃到的果實數量。

# 飛黃騰達

## 題目想法

一開始看到這一道題目的時候，我嘗試了很多不同的方法，像是 DFS、BFS、動態規劃以及直接模擬，但是都沒有辦法找到一個有效率的解法，因此卡住了一段時間。

後來我開始重新分析題目的條件，嘗試把整個問題畫成圖來觀察。當我把每個果實的座標標示出來後，發現如果先固定 x 座標的順序，整個問題就會變得清楚很多。

因為飛黃只能往右上方移動，所以選擇的果實必須滿足 x 座標與 y 座標都不能減少。因此如果我先按照 x 座標排序，剩下的問題就變成在排序後的 y 座標序列中，尋找一個可以相等的遞增子序列。

也就是轉換成 LIS （Longest Increasing Subsequence，最長遞增子序列）的問題，只是這裡因為座標可以相等，所以需要找的是最長可以相等的遞增子序列。

想到這個轉換之後，整題的方向就變得非常明確。

## 解題過程

首先我將所有果實的座標存入 TEMP 中，因為需要同時保存 x 與 y 座標，所以使用 vector 儲存 pair。

接著將所有果實按照 x 座標排序。

排序完成後，由於 x 座標已經符合飛黃移動時不能減少的條件，因此後續只需要考慮 y 座標是否也符合遞增條件。

接著建立 dp 陣列，其中：

dp[i] 代表以第 i 個果實作為最後一個果實時，最多可以吃到的果實數量。

初始化時，每個果實都至少可以自己被吃到，所以全部設定為 1。

接下來使用兩層迴圈進行 LIS：

如果前面的果實 j 的 y 座標小於等於目前果實 i 的 y 座標，代表飛黃可以從果實 j 移動到果實 i，因此更新：

dp[i] = max(dp[i], dp[j] + 1)

最後找出所有 dp 中的最大值，就是飛黃最多可以吃到的果實數量。

## 解題方法思考

這一題本身的實作並不困難，但是最大的難點在於如何把題目轉換成適合的模型。

一開始我一直想從移動方式下手，嘗試使用 DFS 或 BFS 去搜尋所有可能路徑，但是後來發現這樣會忽略掉題目的數學規律，也容易造成大量重複搜尋。

重新觀察座標關係後，我發現飛黃吃果實的順序其實就是一條座標不下降的鏈。

因此先固定 x 座標排序後，就可以把二維座標問題轉換成一維的 LIS 問題。

這也是這題最重要的地方。如果沒有想到這個轉換方式，就很難寫出解法；但是一旦發現它和 LIS 的關係，後面的程式實作就會變得非常簡單。

## 複雜度分析

時間複雜度：

O(n²)

原因是首先需要對所有果實進行排序，時間複雜度為 O(n log n)，接著使用兩層迴圈進行 LIS 動態規劃，因此主要花費在 O(n²)。

空間複雜度：

O(n)

原因是需要使用 vector 儲存所有果實座標，以及使用 dp 陣列記錄每個位置的最大結果。

## 學習心得

這一題讓我學到，遇到看起來像搜尋問題的題目時，不一定真的要使用 DFS 或 BFS。

有時候如果能仔細觀察題目的限制，把問題重新轉換成另一種形式，可能會找到更簡單的解法。

這題最大的收穫就是學會如何從二維座標問題轉換成 LIS 問題。以前我看到座標移動類型的題目，常常會直接想到搜尋，但這次讓我了解到，分析問題的結構和找出規律，往往比直接套用熟悉的演算法更加重要。
