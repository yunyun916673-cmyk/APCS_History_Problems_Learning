# 星際探險

## 題目意思
你是一位星際探險家，即將進入一條由 $n$ 個區段組成的「星際隧道」。每個區段都帶有特定的數值：正數代表能增加能量值的「能量」，負數則代表會減少能量值的「輻射」。

你必須在隧道中選擇一段**連續**的區段進行探索。幸運的是，你的太空船上配有防護盾，最多可以選擇啟動 $k$ 次來抵擋輻射（也就是將該區段的負數數值無視，當作 0 計算）。
請計算出在選擇最佳連續區段、並合理使用防護盾的情況下，你最多可以獲得多少總能量值。（如果所有探索路線都會導致能量減少，你可以選擇不進入隧道，此時總獲得能量為 0。）

## 輸入格式
第一行包含兩個整數 $n$ 與 $k$，分別代表星際隧道的區段總數，以及防護盾最多可使用的次數。
第二行包含 $n$ 個整數 $a_1, a_2, ... , a_n$，代表隧道中依序每個區段的能量或輻射數值。數字之間以空白隔開。

## 輸出格式
請輸出一個整數，代表探險家可以獲得的「最大總能量值」。

## 範圍限制
- $1 <= n <= 1.5 \times 10^5$
- $0 <= k <= 20$
- $-10^4 <= a_i <= 10^4$

# 星際探險
## 題目想法
這題的核心邏輯讓我聯想到以前寫過的「美食博覽會」問題，雖然兩題要求的具體內容不同，但動態規劃（DP）的思維邏輯與狀態定義非常相似。這題的目標是找出一段連續區段的最大總和，並且可以選擇性地跳過（使用防護盾）負數。這其實就是帶有條件限制的 Kadane's Algorithm 變體。
## 解題過程
我實作了兩個版本：2D 陣列版與 1D 滾動陣列（空間優化）版。
一開始先用 2D DP 來建構邏輯，定義 dp[i][j] 為：「走到第 i 個時間點（區段）時，還剩下 j 個防護盾可以使用的最大能量」。
 * 初始化與無防護盾轉移：進入迴圈後，先處理完全不使用防護盾的狀態 dp[i][k] = max(dp[i-1][k] + line[i], line[i])。如果單取當前區段的值較大，代表前面的累積已經變成負擔（爛掉了），直接從這個點重新開始。
 * 防護盾轉移：接著倒序執行 k 次迴圈，處理剩下 j 個防護盾的狀態轉移：dp[i][j] = max(dp[i-1][j] + line[i], dp[i-1][j+1])。
 * 空間優化：觀察到第 i 個時間點的狀態只會用到第 i-1 個時間點的數據，因此將空間壓平，利用 nxt 陣列暫存當前狀態，再覆蓋回一維的 dp 陣列中，大幅節省記憶體。
## 解題方法思考
這題最精華的地方在於狀態轉移的兩個選擇：
 * 不使用防護盾：繼承上一步同為 j 個防護盾的狀態，並加上當前區段的數值 dp[i-1][j] + line[i]。
 * 使用防護盾：消耗一個防護盾（即看向上一步還有 j+1 個防護盾的狀態），且不加上當前區段的數值（免疫負面影響） dp[i-1][j+1]。
可能有人會疑惑：「題目要求連續區段，這裡怎麼沒有明確處理『連續』的問題？」
其實程式碼中的 max 運算已經巧妙地把 Kadane's Algorithm 的核心思想融入其中。當前面的區段和加上當前數值，還不如直接拿當前數值本身大時，max 就會果斷捨棄前面的區段，自動達成「連續區段重新計算」的效果，不需要額外去紀錄起點或終點。
## 複雜度分析
### 時間複雜度：O(NK)。
需要遍歷 N 個區段，每個區段內部進行 K 次防護盾狀態的轉移。
### 空間複雜度：
   * 2D 版本：O(NK)。
需要開一個完整的二維 DP 表格。
   * 1D 優化版：O(K)。
僅保留當前與上一步的狀態（長度皆為 K+1 的 dp 與 nxt 陣列），空間利用極致。
## 學習心得
這是一題高度抽象的動態規劃題。雖然最後寫出來的程式碼非常簡潔俐落，但實際上要在腦海中構思、除錯並維護這個 DP 轉移式，是一件非常消耗腦力的事情。如果沒有足夠的經驗累積，很難直覺地把「連續最大子陣列」加上「次數限制的跳過操作」融合成這樣優美的轉移方程式。這題讓我深刻體會到，DP 的精髓往往在於狀態定義的精準度與思維的抽象化能力。
