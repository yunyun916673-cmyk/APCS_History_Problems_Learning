# 雙通道
## 題目意思
你是一名正在探索遠古遺跡的冒險者。這座遺跡內部有兩條狹窄且深邃的魔法通道，通道內各有若干個房間。為了通關，你必須把兩條通道內的所有房間都探索完畢。

你身上帶著一個初始魔力值為 0 的「魔力儲存背包」。每次行動時，你只能從兩條通道中「挑選其中一條，並進入最靠外側尚未探索的房間」。

房間內可能藏有魔力泉源（正整數），會將魔力加進你的背包中。

房間內也可能藏有怪物或陷阱（負整數），會消耗你背包裡的魔力。

為了保證生命安全，在整個探索過程中，你的魔力值絕對不能低於 0，否則就會被遺跡的詛咒吞噬。

作為一名精打細算的冒險者，你不想要帶著過於笨重的高容量背包。請你在所有「保證魔力永不低於 0」的探索順序中，

找出能讓過程中的「魔力最高峰值」越小越好的路線，並計算出這個「最小化的最大魔力值」是多少。這決定了你出發前究竟需要買容量多大的背包！

## 輸入格式
第一行包含兩個正整數 N 與 M，分別代表第一條通道與第二條通道的房間數量。
第二行包含 N 個整數，代表第一條通道從入口到深處的房間魔力變化數值。
第三行包含 M 個整數，代表第二條通道從入口到深處的房間魔力變化數值。

## 輸出格式
輸出一個整數，代表在保持魔力值隨時大於等於 0 的前提下，整個探索過程中背包出現過的最大魔力值，最小可以是多少。
如果這兩條通道的配置極度險惡，無論你怎麼安排探索順序，魔力值都無可避免地會跌破 0，請輸出 -1 代表無人生還。

## 範圍限制
1 <= N, M <= 1000

-1000000 <= 房間的魔力變化數值 <= 1000000

# 雙通道

## 題目想法
這道題目要求尋找「最大值的最小值」，這是一個非常經典的「對答案進行二分搜尋 (Binary Search on Answer)」特徵。
既然已經決定外層用二分搜尋來界定最大值限制，那麼內層的 `check` 驗證函式，自然就會想到利用「雙指標動態規劃 (2D DP)」來模擬從兩個堆疊中抽取數字的過程。

## 解題過程
1. **前處理**：為了快速計算抽取的數字總和，一開始先將兩個堆疊 A 與 B 的輸入轉換為「前綴和 (Prefix Sum)」。
2. **狀態定義**：定義一個二維陣列 dp[i][j]，代表「從堆疊 A 拿了 i 個數字，從堆疊 B 拿了 j 個數字」的狀態是否可以合法抵達。
3. **二分驗證**：利用二分搜給定一個最大值上限 X，如果透過 DP 發現 dp[N][M] 可以是 true，就代表這個 X 是可行的，接著縮小右邊界尋找更小的可能；反之則放大左邊界。

## 解題方法思考
在二分搜尋的 `check` 函式中，動態規劃的狀態轉移條件是整題的核心。要讓 dp[i][j] 為 true，必須嚴格同時滿足以下條件：
1. **路徑連通性**：必須能夠從先前的合法狀態走過來，也就是 dp[i-1][j] (上一步從 A 拿) 或 dp[i][j-1] (上一步從 B 拿) 其中至少有一個必須是 true。
2. **非負底線**：當前拿取數字的總和必須大於等於 0。
3. **不超上限**：當前拿取數字的總和，必須小於或等於目前二分搜尋所界定的最大值 X。
只有當這幾個條件都成立時，才能將該狀態設為可行。一旦確立了這個判斷標準，DP 的迴圈寫起來就非常直觀了。

## 複雜度分析
- **時間複雜度**：O(N * M * log(Sum))。
- 二分搜尋的次數取決於所有正數總和 S (大約是 log(S) 次)，而每一次的驗證都需要跑完一次大小為 N * M 的雙層迴圈。
- 因為事前做了前綴和，內部狀態計算是 O(1)，整體時間在此題限制下能輕鬆通過。
- **空間複雜度**：O(N * M)。使用了一個 N+1 乘 M+1 的布林陣列來記錄 DP 狀態。

## 學習心得
這題算是「難者不會，會者不難」的典型。一旦看穿了「二分搜搭配 DP 驗證」的這個組合套路，實際實作起來其實十分輕鬆。
另外，在寫程式的當下也有察覺到，因為 dp[i][j] 的狀態只依賴於上一列 [i-1] 以及同一列的左方 [j-1]，其實可以直接利用 (Invert) 的技巧將空間壓縮成一維。
雖然這次為了直觀沒有特別去改寫，但能在實作時下意識地發現這層空間優化的可能，對自己掌握 DP 的熟悉度是一次很好的印證。
