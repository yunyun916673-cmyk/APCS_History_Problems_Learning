# 老茶行焙茶爐火候記錄
## 題目意思
高山茶行在製茶季有一套自動控溫焙茶爐，初始火候段數為基準值 0。整段焙茶排程共有 2 乘以 N 個連續時段，必須恰好包含 N 次「升溫一級」與 N 次「降溫一級」。

為了避免茶葉焦苦或焙火不足，火候在任何時段都不得低於基準值 0（含），也不得高於上限 N（含）。最後在第 2 乘以 N 個時段結束時，火候必須精準回到基準值 0。請計算共有多少種合法的火候升降排程。

## 輸入格式
輸入只有一行，包含一個正整數 N，代表升溫與降溫各 N 次（總時段數為 2 乘以 N）。

## 輸出格式
輸出一個整數，代表合法的火候升降排程總數，並換行。

## 範圍限制
原始題目（chain）的輸入檔與輸出檔皆為單一測試資料，測資範圍中 N 介於 2 到 25 之間（含 2 與 25）。

# 老茶行焙茶爐火候記錄
## 題目想法
這題的核心在於計算總共 2 * N 步的序列中，包含 N 次正向變化與 N 次負向變化，且過程中累積數值始終維持在 0 到 N 之間、最終回到 0 的合法組合數。觀察測試資料（N = 3 時為 5，N = 4 時為 14，N = 18 時為 477638700），這正好對應到經典的卡塔蘭數列（Catalan Number）。

## 解題過程
狀態定義：建立二維陣列 dp[i][j]，其中 i 代表目前已執行的總步數（範圍 0 到 2 * N），j 代表目前的累積高度或淨差值（範圍 0 到 N）。

初始條件：設定起點 dp[0][0] = 1，以及第一步必為正向變化 dp[1][1] = 1。

狀態轉移：從 i = 2 遍歷至 2 * N，針對每個合法的狀態 j（0 到 N）：

若 j 大於 0，代表這一步可以由前一步的 j - 1 向上轉移而來，累加 dp[i - 1][j - 1]。

若 j 小於 N，代表這一步可以由前一步的 j + 1 向下轉移而來，累加 dp[i - 1][j + 1]。

輸出結果：遍歷結束後，輸出 dp[2 * N][0] 即為所有合法序列的總數。

## 解題方法思考
這題其實可以直接套用卡塔蘭數的組合數學公式 C(2N, N) / (N + 1) 在 O(N) 時間內算完，但使用二維動態規劃（DP）的寫法更直觀，也更容易應對題目若額外加入「特定高度限制」或「禁止經過某些狀態」的變化題型。此外，由於 N = 25 時的結果高達 4.86 乘以 10 的 12 次方，超過 32 位元整數上限，因此全程必須使用 long long 儲存數值以防止溢位。

## 複雜度分析
### 時間複雜度：O(N^2)。
外層迴圈執行 2 * N 次，內層迴圈執行 N + 1 次，在 N 最大為 25 的情況下僅需約 1300 次基本運算，執行時間遠低於限制。

### 空間複雜度：O(N^2)。
配置了大小約為 (2 * N + 5) 乘以 (N + 5) 的二維 vector，記憶體佔用極小（若改用滾動陣列則可進一步壓縮至 O(N)）。
