# 3D_LCS
## 題目意思
國立歷史博物館最近出土了三批分別來自不同朝代的殘缺竹簡文獻，每批文獻上記錄著一連串的數字編號序列。為了找出這三個朝代之間技術傳承的關聯性，研究團隊希望找出這三個序列中的「三維最長公共子序列」（3D Longest Common Subsequence）。
給定三個長度分別為 N_a、N_b、N_c 的序列 A、B、C，請找出這三個序列中最長的公共子序列長度，並按順序輸出該子序列的所有元素。若不存在任何公共子序列（長度為 0），則輸出 -1。
## 輸入格式
第一行輸入三個正整數 N_a、N_b、N_c，分別代表三個序列的長度。
第二行包含 N_a 個整數，代表序列 A 的元素。
第三行包含 N_b 個整數，代表序列 B 的元素。
第四行包含 N_c 個整數，代表序列 C 的元素。輸出格式若最長公共子序列長度為 0，請輸出 -1。
若長度大於 0，第一行輸出最長公共子序列的長度；隨後依序輸出該公共子序列中的每個元素，每行一個。
## 範圍限制
N_a, N_b, N_c 的範圍及序列中的數值皆在合理競程測資範圍內。

# 3D_LCS
## 題目想法
這題是經典「最長公共子序列（LCS）」問題的延伸。從二維擴展到三維時，狀態定義必須同步考慮三個序列的當前指標 i、j、k。
當三個序列的元素相同時，長度由 dp[i-1][j-1][k-1] + 1 轉移。若不相同，則取三個方向退一步的最大值。最後透過逆向回溯來還原出實際的子序列元素。
## 解題過程
輸入與初始化：讀取三個序列長度 N_a, N_b, N_c 並配置對應大小的 1-based 向量。
三維 DP 遞迴建構：運用三重迴圈遍歷所有狀態：若 A[i] == B[j] == C[k]，則 dp[i][j][k] = dp[i-1][j-1][k-1] + 1$。否則取 max(dp[i-1][j][k], dp[i][j-1][k], dp[i][j][k-1])。
邊界與輸出檢查：若最終長度為 0 則輸出 -1。路徑回溯：從 (N_a, N_b, N_c) 開始逆向追蹤，當三者相等時記錄該元素並將三個指標同時減 1，否則依據哪一個方向的 DP 值與當前值相等來決定回退方向。
## 解題方法思考
狀態轉移：三維 DP 空間複雜度與時間複雜度皆為 O(N_a N_b N_c)。回溯順序：由於回溯是從終點往起點進行，收集到的路徑順序會是相反的，因此需要透過 vector 儲存後再反向輸出，確保印出順序正確。
## 複雜度分析
### 時間複雜度：O(N_a*N_b*N_c)
適用於中小型資料範圍。
### 空間複雜度：O(N_a*N_b*N_c)
用於儲存三維 DP 表與狀態。
## 學習心得
透過這題熟悉了高維度動態規劃的狀態定義與空間管理技巧。特別是在處理 3D 陣列的索引邊界時，務必確保所有序列的宣告大小都包含 1-based 的偏移量，避免發生難以察覺的記憶體越界錯誤。
