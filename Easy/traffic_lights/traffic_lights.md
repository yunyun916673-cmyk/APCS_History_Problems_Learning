# 等紅綠燈
## 題目說明
有一個交通號誌會一直重複以下循環：
綠燈持續 a 秒。
接著紅燈持續 b 秒。
然後再次回到綠燈，如此不斷循環。
現在有 n 位小朋友同時開始騎腳踏車，每位小朋友完成一圈所需的時間分別為 t1、t2、…、tn 秒。
當某位小朋友完成一圈時：
如果此時是綠燈，可以立即停止，不需要等待。
如果此時是紅燈，必須等到下一次綠燈開始才能停止。
請計算所有小朋友等待紅燈的總秒數。
## 輸入格式
第一行包含兩個整數 a、b，分別表示綠燈與紅燈持續的秒數。
第二行包含一個整數 n，表示小朋友的人數。
第三行包含 n 個整數，依序表示每位小朋友完成一圈所需的時間。
## 輸出格式
輸出一個整數，表示所有小朋友等待紅燈的總秒數。

# 等紅綠燈（Traffic Lights）

## 題目想法

一開始看到這個題目時，我先暫定它是利用數學方式進行判斷，因此先朝數學式的方向思考。


## 解題過程

我先確認題目中的各項條件，
由於題目提到資料沒有特別限制，因此為了避免整數溢位，我決定全部使用 long long。

接著依序輸入：

- a：綠燈時間
- b：紅燈時間
- n：人數

再建立答案變數 ans，並利用 n次迴圈依序輸入每位小朋友騎完一圈所花費的時間 t。


## 核心觀察

我發現紅燈與綠燈會一直循環，因此需要知道目前位於一個循環中的哪個位置，故而用：
t % (a + b)

接著判斷：
t % (a + b) > a

若成立，代表目前已經進入紅燈，需要等待。

而等待時間為：
a + b - t % (a + b)

因此直接更新ans：
ans+=a+b-t%(a+b);

## 時間複雜度

每個人只會判斷一次，因此時間複雜度為：

O(n)

空間複雜度為：

O(1)


## 學習心得

這是一題基礎的數學判斷題。

我認為這題最重要的是先觀察出紅綠燈具有固定的循環週期，再利用餘數運算找出目前位於哪個階段。

藉由這題，我更加理解如何利用題目的規律，將原本可能需要模擬的過程轉換成數學運算，讓程式更簡潔且效率更高。
