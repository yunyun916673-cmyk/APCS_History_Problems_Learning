# 成績指標

## 題目敘述
給定一班學生的考試成績，請先將所有成績依照由小到大的順序排列。
接著找出：
所有 未達 60 分 的成績中，分數最高的一筆。
所有 60 分以上（含 60 分） 的成績中，分數最低的一筆。
如果沒有未達 60 分的成績，表示全班都及格，輸出 best case。
如果沒有 60 分以上的成績，表示全班都不及格，輸出 worst case。
## 輸入
第一行輸入一個整數，表示學生人數。
第二行輸入所有學生的成績。
## 輸出
共輸出三行：
依照遞增順序輸出所有成績。
輸出未及格成績中的最高分；若不存在則輸出 best case。
輸出及格成績中的最低分；若不存在則輸出 worst case。

# 成績指標
## 題目想法
一開始看到這一題的時候，我先思考我需要維護哪些資訊。這一次我要維護的有三個東西，一個是所有學生的成績，一個是不及格中的最高分，另外一個則是及格中的最低分。
因為題目的測資範圍很小，分數也只有 0～100，所以使用 int 就足夠了。我也發現題目要求最後要將所有成績由小到大輸出，因此一定要把所有分數先存起來，再進行排序。
除了儲存所有成績之外，我也想到可以在讀入分數的同時，直接更新最高不及格分數以及最低及格分數，這樣就不用等排序完之後再重新掃描一次所有資料。
## 解題過程
一開始先輸入題目所要求的人數 n，並建立兩個變數：
fail_but_highest：代表不及格但最高分的成績，我先初始化為 -1，表示目前還沒有任何不及格的學生。
pass_but_lowest：代表及格但最低分的成績，我先初始化為 1e9，表示目前還沒有任何及格的學生。
接著建立一個長度為 n 的 vector<int>，students，用來儲存所有學生的成績。
之後進入迴圈，每次先輸入一位學生的分數，再把分數放進 students 中。如果分數大於等於 60，就嘗試更新最低及格分數；否則就更新最高不及格分數。
當所有資料都讀入完成後，我再將 students 進行排序，並依序輸出所有成績。
最後再判斷兩個指標是否有被更新。如果 fail_but_highest 從頭到尾都沒有被更新，就代表所有人都及格，因此輸出 best case；否則輸出更新後的最高不及格分數。
最低及格分數也是相同的道理。如果 pass_but_lowest 一直沒有被更新，就代表全班都沒有及格，因此輸出 worst case；否則輸出更新後的最低及格分數。
## 解題方法思考
這題其實有很多種做法，例如先把所有成績排序，再從排序後的結果找出最高不及格分數和最低及格分數。
不過我最後選擇在輸入資料時就同步維護這兩個成績指標，因為這樣可以在讀入資料的同時完成更新，不需要再額外掃描一次所有成績，程式邏輯也比較直觀。
這題主要是在練習變數維護、if-else 判斷，以及陣列排序等基礎程式設計能力。
## 複雜度分析
### 時間複雜度：
O(n log n)
主要花費時間的地方是將所有成績排序，排序需要 O(n log n) 的時間，而讀入資料、更新成績指標以及最後輸出皆只需要 O(n)，因此整體時間複雜度由排序決定。
### 空間複雜度：
O(n)
需要使用一個長度為 n 的 vector 儲存所有學生的成績，因此額外空間與學生人數成正比。
## 學習心得
這一題其實算是一題很基礎的題目，主要是在練習如何維護變數、利用 if-else 更新資料，以及使用 vector 搭配 sort 對陣列進行排序。
雖然整體邏輯不困難，但也讓我再次熟悉了如何在讀入資料的同時維護需要的資訊，而不是所有事情都等到最後再處理。這種邊讀邊更新答案的思考方式，在之後遇到更多需要維護最大值、最小值或其他狀態的題目時，也會是一個很常用的技巧。
