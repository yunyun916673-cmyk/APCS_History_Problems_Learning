# 迷宮探索
## 題目意思
有一個自動化探索機器人正在探測一個未知的地下機房迷宮，這個迷宮由許多房間組成，並呈現「樹狀結構」。每個房間都有一個正整數編號。
房間的通道數量由它的編號決定：

若編號為「偶數」，則該房間有 2 條通道分支（左、右）。

若編號為「奇數」，則該房間有 3 條通道分支（左、中、右）。

機器人會使用深度優先搜尋（DFS）的方式探測迷宮，規則如下：

當機器人第一次走到一個新房間時，會將該房間的編號記錄下來。

接著，機器人會「由左至右」依序走訪該房間的所有分支通道。

如果某條通道是死路，機器人會記錄下數字 0，然後繼續探測下一條通道。

如果該房間的所有通道都探測完畢，機器人就會退回到上一個房間。
最後，機器人走完全部迷宮後，會留下一串由房間編號與 0 所組成的數字序列。

你的任務是根據這串數字序列，推算出整個迷宮的結構，並計算出：所有「相鄰（直接連接）的兩個房間」編號相差之絕對值的總和。

## 輸入格式
輸入包含一連串的整數，代表機器人探測後記錄下來的數字序列，數字與數字之間以單一空白字元分隔。

## 輸出格式
輸出一個整數，代表所有相鄰房間編號相差絕對值的總和。請注意，最終加總的答案可能會非常大，會超過 32 位元有號整數的上限 (超過 2^31 - 1)，請記得使用 64 位元整數型態 (如 long long) 來儲存答案。

## 範圍限制
序列中的整數總數不超過 1,000,000 個。

每個房間的編號均大於 0 且不超過 100,000。

測資保證迷宮（樹狀結構）的最大深度不會超過 40 層。

# 迷宮探索
## 題目想法
這題是很經典的深度優先搜尋（DFS）基本應用。題目提供的輸入格式，恰好就是樹狀結構經過 DFS 走訪後產生的先序遍歷序列，因此完全不需要額外建圖或處理複雜的回溯機制，可以直接順著陣列的順序來還原樹的結構。
## 解題過程
在設計 DFS 函式時，為了計算相鄰節點的差值，我在參數中額外放入 pnt 來代表「父節點」的數值。當讀取到有效的新節點時，直接計算當前節點與父節點數值的絕對值差，並將結果累加到全域變數 ans 中，這樣就能在遍歷的過程中同步完成所有答案的更新。
## 解題方法思考
處理每個節點時，先根據題意檢查該節點的數值是奇數還是偶數，藉此決定後續的分支數量：奇數會有 3 條分支，偶數則有 2 條分支。接著只要往相應的方向遞迴呼叫對應次數的 DFS 即可。如果遇到 0 則代表死路，直接 return 返回上一層，完全順著給定的格式走即可。
## 複雜度分析
### 時間複雜度：O(N)，
其中 N 為輸入數字序列的總長度。每個數字都只會被讀取及走訪一次。
### 空間複雜度：O(N)，
主要的空間花費在於儲存整個輸入序列的 vector。至於 DFS 遞迴堆疊（Call Stack）的深度，根據題目保證最大深度不超過 40 層，因此這部分的空間消耗極小。
## 學習心得
這是一道練習 DFS 與遞迴思維的好題目。利用題目給定的前序遍歷順序，直接結合遞迴呼叫的特性來解題，不僅省去了建圖的麻煩，也讓程式碼變得非常直觀精簡，加深了對於樹狀結構遍歷順序與遞迴關係的理解。
