# 魔法迷宮

## 題目敘述

有一個迷宮，由 H×W 個方格組成，其中 H 為垂直方向的格數，W 為水平方向的格數。

從上往下數第 i 列、從左往右數第 j 欄的方格 (i,j)，如果 Sij 是 #，則該方格是牆壁；如果 Sij 是 .，則該方格是道路。

有一名魔法師位於 (Ch,Cw)。他可以進行以下兩種移動：

移動 A：
走到與目前所在方格上下左右相鄰的道路方格。

移動 B：
使用魔法，將自己傳送到以目前所在方格為中心的 5×5 區域中的某個道路方格。

在這兩種情況下，他都不能走出迷宮。

至少需要使用幾次魔法，才能抵達 (Dh,Dw)？

限制

1≤H,W≤10^3

1≤Ch,Dh≤H

1≤Cw,Dw≤W

Sij 是 # 或 .

SChCw 和 SDhDw 是 .

(Ch,Cw) ≠ (Dh,Dw)


## 輸入

輸入由標準輸入提供，格式如下：

SH1 … SHW

輸出魔法師抵達 (Dh,Dw) 所需使用的最少魔法次數。

如果無法抵達 (Dh,Dw)，請輸出 -1。

# 魔法迷宮

## 題目想法

一開始看到這一題的時候，我先想到的是直接使用 BFS，再搭配記憶化處理。因為這一題的重點就是要找到到達每個位置所需要的最少魔法次數，所以我可以用一個陣列記錄目前到達每個位置的最少魔法次數。

不過後來思考之後，我發現這一題其實可以使用 01BFS。因為普通移動不需要消耗魔法，可以看成權重 0，而使用魔法移動則需要消耗一次魔法，可以看成權重 1。

這時候就可以使用 deque 來處理，將不需要消耗魔法的移動放到前面，而需要消耗一次魔法的移動放到後面。

其實這個方法我已經很久沒有使用了，所以一開始並沒有想到 01BFS。後來重新想到 deque 的用法，也算是順便複習了這個之前學過的方法。

## 解題過程

這一題我使用 GRID 儲存整張地圖，使用 MEMO 儲存到達每一個位置所需要的最少魔法次數。

在主要的函式 MAIN 裡面，先完成地圖和 MEMO 的初始化，並將起點的魔法次數設為 0，接著將起點放入 deque 中。

進入 BFS 後，我會先從 deque 的前面取出目前的位置。

接著先嘗試往上下左右四個方向移動。如果下一個位置是道路，而且使用目前的魔法次數就可以得到更好的結果，就更新 MEMO。

因為這種移動不需要消耗魔法，所以會把新的位置放到 deque 的前面。

接下來再檢查以目前位置為中心的 5×5 區域，看看使用一次魔法可以傳送到哪些道路。如果可以讓某個位置得到更少的魔法次數，就更新 MEMO。

因為這次移動會消耗一次魔法，所以把新的位置放到 deque 的後面。

這樣利用 0 權重放前面、1 權重放後面的方式，就可以讓需要較少魔法次數的狀態優先被處理，也可以避免同一個位置被大量重複處理。

最後只需要查看 TRTC 這個位置的 MEMO，也就是到達終點所需要的最少魔法次數。如果仍然沒有被更新，就代表無法到達終點，輸出 -1。

## 解題方法思考

一開始我只是單純使用 BFS 加上記憶化處理，但後來發現這一題的兩種移動其實有不同的權重。

普通移動不需要消耗魔法，可以視為 0，而使用魔法則可以視為 1。因此與其使用一般的 BFS，不如使用 01BFS。

01BFS 可以利用 deque 來處理這兩種不同的權重。0 的移動使用 push_front，1 的移動使用 push_back，讓目前需要較少魔法次數的位置可以優先被處理。

這樣除了可以找到最少的魔法次數，也能減少很多不必要的重複處理，讓整體效率更好。

這一題也讓我重新複習了 01BFS。因為我已經很久沒有使用 deque 來做這種分層處理，一開始其實完全沒有想到這個方法，不過重新想起來之後，就發現這一題其實非常適合使用 01BFS。

## 複雜度分析

### 時間複雜度：

O(HW)

每個位置會檢查上下左右四個方向，以及最多 25 個位置的 5×5 區域。因為這些數量都是固定的常數，所以整體可以視為 O(HW)。

### 空間複雜度：

O(HW)

主要使用 GRID 儲存地圖、MEMO 儲存每個位置的最少魔法次數，以及 deque 儲存需要處理的位置。

## 學習心得

這一題讓我重新複習了 01BFS。

我一開始其實只是想用 BFS 加上記憶化處理，後來才發現這一題的移動可以分成 0 和 1 兩種權重，因此可以使用 deque 來做 01BFS。

因為我已經很久沒有使用這一種方法，所以一開始沒有馬上想到，甚至連 deque 的一些操作名稱都需要重新想一下。不過重新使用一次之後，也算是把之前學過的東西重新複習回來。

這一題也讓我再次注意到，看到 BFS 類型的題目時，不一定只能直接使用普通 BFS。如果不同移動的代價不同，也可以進一步觀察它是不是適合使用 01BFS 或其他最短路方法。
