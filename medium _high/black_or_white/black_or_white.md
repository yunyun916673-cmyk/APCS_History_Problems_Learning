# 偶數關係

## 題目敘述

有一棵包含 N 個頂點的樹，頂點編號為 1 到 N。第 i 條邊連接頂點 ui 和 vi，邊的長度為 wi。

請將每個頂點塗成白色或黑色，使得任意兩個顏色相同的頂點，其間的距離必須為偶數。所有頂點使用相同顏色也是允許的。

請輸出任意一種符合條件的染色方式。可以證明，在題目的限制下，一定存在至少一種符合條件的染色方式。

限制

1 ≤ N ≤ 10⁵

1 ≤ ui < vi ≤ N

1 ≤ wi ≤ 10⁹

所有輸入值皆為整數。


## 輸入格式

輸入格式如下：



N  
u1 v1 w1  
u2 v2 w2  
⋮  
uN-1 vN-1 wN-1

其中：

第一行輸入頂點數 N。

接下來 N − 1 行，每行輸入 ui、vi、wi，表示一條連接 ui 和 vi 的邊，其長度為 wi。


## 輸出格式

輸出 N 行。

第 i 行輸出頂點 i 的顏色：

輸出 0 表示塗成白色。

輸出 1 表示塗成黑色。


只要輸出的染色方式符合題目條件即可。

# 偶數關係

## 題目想法

一剛開始看到這一道題目的時候，我就直覺想到這題應該可以用 BFS。

為什麼會想到 BFS？因為我先從最小的單位來看。

假設點 A 和點 B 之間有一條邊，如果點 A 是白色，那麼點 B 的顏色就要看 AB 這條邊的長度。如果這條邊是偶數，那麼點 B 可以和點 A 使用相同的顏色；但如果這條邊是奇數，那麼點 B 就一定要和點 A 使用不同的顏色。

再往後延伸，如果連續經過幾條邊都是偶數，那麼不管經過幾次，總距離都還是偶數。但只要中間遇到一次奇數邊，整體的奇偶性就會改變。

所以我發現，我其實只需要在遇到奇數邊的時候，把顏色切換一次，後面再繼續往外延伸就可以了。

從一條邊的情況開始思考，再把這個規律一路延伸到整棵樹，就可以得到最後的染色方式。

## 解題過程

我先建立 N，然後使用 colors 儲存每一個節點目前的顏色，再使用 ship 儲存節點與節點之間的關係，以及兩個節點之間的邊長。

在 BFS 裡面，因為這是一張無向圖，所以我使用 visited 來保證每個節點不會被重複走訪。

每走到一個節點，我就會去看它旁邊所有還沒有走過的子節點，然後判斷目前節點和這個子節點之間的邊是奇數還是偶數。

如果邊長是奇數，就把子節點的顏色改成和目前節點不同的顏色；如果邊長是偶數，就讓子節點和目前節點使用相同的顏色。

來到主函式 main，因為我只需要知道邊長是奇數還是偶數，所以在讀入邊長之後，我直接全部取模二。

這樣之後在 BFS 裡面，就不需要再處理實際的邊長，只需要判斷它是 0 還是 1。

BFS 完成之後，我只需要把每一個節點的顏色依序輸出，就可以得到其中一種符合條件的染色方式。

## 解題方法思考

這一題我一開始並沒有想要直接從所有點之間的距離去判斷，因為如果直接去考慮任意兩個點之間的距離，問題會變得很複雜。

所以我先把問題縮小到兩個相鄰節點之間。

我發現只要知道一條邊是奇數還是偶數，就可以決定下一個節點的顏色。奇數代表顏色需要切換，偶數代表顏色保持不變。

接著因為整棵圖是一棵樹，所以從一個節點往外延伸時，可以利用 BFS 一層一層把這個規律傳出去。

我覺得這題比較重要的地方，就是把一個看起來需要考慮所有點之間距離的宏觀問題，先拆成兩個相鄰點之間的小問題，找到其中的規律之後，再把這個規律一路放大回整棵樹。

所以這題考驗的其實不只是 BFS，而是能不能把一個很宏觀的大問題化成微觀的小問題，找到規律之後，再以點作面，把這個規律延伸回整個問題。

## 複雜度分析

### 時間複雜度：

O(N)

因為這是一棵有 N 個節點、N-1 條邊的樹，BFS 會將每個節點走訪一次，每條邊也只會被檢查有限次，所以整體時間複雜度是 O(N)。

### 空間複雜度：

O(N)

colors、visited 和 ship 都需要儲存與 N 個節點相關的資訊，而 BFS 的 queue 最多也會存放 O(N) 個節點，因此空間複雜度是 O(N)。

## 學習心得

我覺得這一題讓我比較有感覺的是，看到題目的時候，不一定要直接去處理題目表面上要求的東西。

這題表面上是在要求任意兩個相同顏色的點，它們之間的距離必須是偶數。如果直接去想任意兩個點之間的距離，會感覺需要處理很多種情況。

但我把問題縮小到最基本的兩個相鄰點之後，就發現其實只需要處理奇數和偶數兩種情況。

找到這個規律之後，再把它一路延伸出去，就可以直接用我很熟悉的 BFS 完成。

所以我認為這題真正考驗的，是能不能把一個很宏觀的問題拆成微觀的規律，再把這個規律重新放大回整個問題。

這也讓我更加知道，遇到題目的時候，不一定要一開始就想完整個問題，而是可以先找到最小的單位，看看它有沒有可以延伸出去的規律。
