# APCS 歷屆題目學習紀錄

## 一、專案動機

為了提升程式設計能力並準備 APCS 檢測，我開始整理歷屆試題的解題過程與學習紀錄。

在練習的過程中，我發現要解決一個問題，最重要的不只是寫出程式，而是分析問題、選擇合適的方法，並透過測試與修正找到更好的解法。

因此，我建立了這個專案，用來記錄自己在 APCS 歷屆試題上的學習歷程。

## 二、學習目標

- C++ 程式設計與常用語法
- 資料結構與演算法基礎
- 分析問題與設計解法
- APCS 歷屆題目練習，累積實際解題經驗

### Python 解法

為了替之後參加 CTF 比賽做準備，我開始學習 Python 的各種語法與應用，並逐漸將其熟悉、內化為自己的工具，因此也補上部分題目的 Python 解法。

其中 Python 檔案中的解法，都是我重新實作並重新思考後得到的結果，會包含我重新思考題目後產生的新想法。

學習內容包含：

- 基礎程式設計
- 常用容器與 STL
- 排序與搜尋
- 二分搜尋
- BFS / DFS 及其各式應用
- 貪婪演算法
- 動態規劃（DP）
- 圖論技巧

## 三、學習方法

每完成一道題目，會整理出：

1. 題目的核心問題
2. 解題思考過程
3. 使用的資料結構與演算法
4. 程式實作方式
5. 遇到的錯誤與改進方法

藉由整理解題紀錄，回顧自己在思考方式上的改變，了解哪些地方需要加強。

## 四、專案整理方式

依照題目難度進行分類：

- 簡單題：基本語法與基礎解題技巧
- 中等題：常見演算法與資料結構應用
- 中高難度題：較複雜的思考與優化
- 困難題：進階演算法與解題策略

每一道題目皆包含程式碼以及個人的解題紀錄。

## 五、我是如何完成這些紀錄的

建立這個專案的初衷，是希望能夠記錄自己的學習與成長過程，讓未來的自己可以回頭看看過去的解題方式，再與現在的自己進行比較，從中看見自己的進步。同時，也能透過這些過去的紀錄，重新發現自己曾經有哪些不足，以及當時是如何一步一步改善的。

既然這個專案的目的在於「記錄自己的成長」，我不希望為了製作紀錄本身而花費大量時間。因此，我選擇以一種更有效率的方式完成這些內容。

我會先使用自己的方式完成每一道題目，並在解題之後，以自己的話描述當時的想法、解題過程、使用的方法，以及完成這道題目後的心得。這些內容都是由我自己思考並整理，而不是直接交給人工智慧產生。

接著，我會將自己寫下的內容交給人工智慧，讓它協助進行語句、文字表達與文章結構上的優化，並整理成適合放在 GitHub 上的 Markdown 格式。最後，我會再將整理完成的內容複製到這個專案中。

我希望透過這種方式，把時間主要花在解題、思考與學習本身，而不是花大量時間在文字排版上。如此一來，這個專案才能真正成為一份記錄我成長過程的歷史，而不是一個需要花費大量時間維護的文件。

## 六、學習成果與反思

透過持續練習 APCS 歷屆題目，我的思考方式逐漸轉變為分析問題、降低複雜度，以及選擇更適合的解法。

在遇到無法解出的題目時，我會藉由測試、查詢資料與重新設計方法來修正錯誤，逐漸累積解決問題的經驗。

## 七、未來規劃

希望持續提升演算法能力，並將程式設計能力延伸至更多元的領域，例如人工智慧、資訊安全與實際專案開發等。
